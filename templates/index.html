How the result works

A set of possibilities is more useful than false certainty.

The model compares your image with examples it learned from. A calibrated rule then keeps the most plausible candidates together, so an uncertain image can show more than one possibility—or honestly say it could not make a reliable call.

The 75% number is a calibration target across a population of in-distribution images, not a promise for this single photo.
